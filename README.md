# Android Learning Project

This is my personal playground for learning Android development.

## Goals

- Learn the basics of building Android apps with **Kotlin**
- Understand the Android project structure (Gradle, manifests, resources)
- Build small apps that each try out a new concept
- Get comfortable working with Git, GitHub, and Claude Code

## Planned topics

- [ ] Hello World app
- [ ] Layouts and UI with Jetpack Compose
- [ ] Handling user input (buttons, text fields)
- [ ] Navigation between screens
- [ ] Lists and RecyclerView / LazyColumn
- [ ] Saving data locally (DataStore, Room)
- [ ] Fetching data from the internet (Retrofit)

## Getting started

1. Install [Android Studio](https://developer.android.com/studio)
2. Clone this repository:
   ```bash
   git clone https://github.com/vanamala/android.git
   ```
3. Open the project in Android Studio and run it on an emulator or device

## Notes

This repo is for learning, so expect experiments, rough edges, and lots of iteration.
